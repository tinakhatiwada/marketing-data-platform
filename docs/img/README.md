## Dashboard

The dashboard has four views. The screenshots below should be placed in `docs/img/` using the filenames shown in the image paths.

### Overview

![Overview dashboard — KPIs and daily trends](docs/img/overview_1.png)

Tracks spend, platform conversions, CPA, GA4 revenue ROAS, and sessions. Daily spend and platform conversion charts show performance trends for the selected reporting period.

![Overview dashboard — channel performance and weekly sessions](docs/img/overview_2.png)

Provides a channel-level breakdown of spend, clicks, CTR, CPC, CPA, sessions, engagement rate, and GA4 ROAS, alongside weekly sessions by channel.

### Campaign performance

![Campaign performance dashboard — KPIs and campaign table](docs/img/campaign_1.png)

Summarizes campaign performance and provides a detailed table for comparing spend, impressions, clicks, CTR, CPC, CPA, platform ROAS, and GA4 metrics.

![Campaign performance dashboard — spend versus CPA and naming checks](docs/img/campaign_2.png)

Visualizes spend against platform CPA and highlights campaigns that fail the configured naming convention.

### Budget pacing

![Budget pacing dashboard — budget and projected spend](docs/img/budget_pacing_1.png)

Compares monthly budgets, month-to-date spend, and projected month-end spend across clients.

![Budget pacing dashboard — detailed pacing table](docs/img/budget_pacing_2.png)

Shows each client's monthly budget, actual spend to date, projected spend, pacing ratio, and pacing status.

### Pipeline health

![Pipeline health dashboard — latest run summary](docs/img/pipeline_health_1.png)

Summarizes recent pipeline quality checks, including check counts, failures, warnings, and individual check results.

![Pipeline health dashboard — detailed quality results](docs/img/pipeline_health_2.png)

Provides additional quality-check details and history to help investigate data freshness, row volume, spend anomalies, and other validation outcomes.
